# ADR-0008: v3.9.0 `UPSTREAM.md` SOTA Framework Lineage, `H2`/`H6` Orca Lane Hubs v2 & Pre-Wall Lake SHA-256 Convergence

- **Status:** Accepted
- **Date:** 2026-11-18
- **Organization:** `https://github.com/native-agent-stack`
- **Evidence:** `UPSTREAM.md`, `orca.yaml`, `harness/scripts/check-adr-catalog.mjs`, `sota-multi-model-workflows` (`ADR-0016`)

## Context

Finalizing `v3.9.0` across `native-agent-stack` required root `UPSTREAM.md` SOTA framework & 18-pin provenance in `dsh-sota-harness`, anchoring the verified `64`-hex `prewallLakeSha256` (`a253421e873441740d5d4b410d993cfa7345fe34b88ec4ab7f4eecd537b3f234`) on `Noesis-Carbon` (`ext4`), and binding `dsh-sota-harness` into `sota-orca-lane-hub.v2` (`H2` / `H6_DEEPSEEK_10LAYER_HARNESS` with live RTH broker contention shield).

## Decision

1. Add root `UPSTREAM.md` documenting all `8` SOTA multi-model orchestration frameworks (`17` binaries, `11` workers, `7` vendors) and `18` `40`-hex quantitative shelf pins.
2. Bind `deepseek-dsh` (`deepseek-v4-pro`) 10-layer verification probes and pre-wall (`<= 2026-10-15`) batch evaluations to `stationary_noesis_carbon_wsl2` via `sota-orca-lane-hub.v2`.
