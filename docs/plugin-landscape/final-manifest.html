Invariant classes

hard failures versus legitimate variation

Hard failures

  • Catalog length equals stats.totals.entries.
  • Every stats total, category count, and layer count is recomputed from the catalog.
  • Category counts sum to the catalog total; IDs are unique.
  • 23 categories; 3 exemplars each; 30 anchors, exactly 3 per layer.
  • 36 prose anchors equal the set extracted from layer-model.md.
  • Index ledger holds: index packages = unique matched npm packages + index-only.
  • Report, layers, landscape, coverage, and architecture agree with stats.
  • Local deliverable links resolve.

Warnings, not failures

  • Duplicate titles: IDs remain unique.
  • Install specs on GitHub-only entries.
  • Multiple entries sharing one npm package.
  • Install/npm presence differences.

These reflect legitimate upstream variation. The warning tests prove they exit 0 with WARN lines.
